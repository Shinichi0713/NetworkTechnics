**ブロードバンドルータ（Broadband Router）** とは、**光回線やADSL、CATVなどの「ブロードバンド（高速）回線」を受けて、家庭や小規模オフィスの内部ネットワーク（LAN）にインターネット接続を分配する機器**です。

一言で言えば、インターネットと家の中のネットワークを繋ぎ、みんなが同時にネットを使えるようにする分配器です。

> __ブロードバンド（Broadband）__
> ブロードバンドとは、語源通り「広い帯域（broad + band）」を使って、 高速かつ常時接続できるインターネット回線の総称です。
> 元々は「広い周波数帯域を使って大量のデータを同時に送る技術」を指していましたが、現在では「従来の電話回線（ダイヤルアップ/ナローバンド）より速い、常時つながったインターネット」 という意味で使われています。

### 主な役割と機能

| 機能                                 | 役割                                                                                |
| ------------------------------------ | ----------------------------------------------------------------------------------- |
| **回線接続**                   | PPPoE（光回線など）やCATVモデムからインターネット回線を受ける                       |
| **NAT / IPマスカレード**       | プロバイダから渡された1つのグローバルIPを、家中の複数機器で共有して使えるように変換 |
| **DHCPサーバー**               | 家の中のPCやスマホに、自動でプライベートIPアドレスを配る                            |
| **無線LAN（Wi-Fi）**           | スマホやノートPCが無線で接続できるようにする（最近の機器はほぼ標準）                |
| **ファイアウォール（基本形）** | 外部からの不必要な通信を遮断する簡易的なセキュリティ機能                            |
| **スイッチングハブ機能**       | 有線LANポート（LAN1〜4など）で、複数の機器を有線接続できる                          |

### イメージ

```
[インターネット] ←──→ [ブロードバンドルータ] ←──→ [家の中のネットワーク]
   (光回線等)        (NAT変換・DHCP・Wi-Fi)      (PC・スマホ・テレビ・ゲーム機)
```

### 補足：呼び方の違い

- **「Wi-Fiルータ」**：無線機能に注目した呼び方。実態は同じ機器が多い
- **「ONU（光回線終端装置）」**：光回線を光信号から電気信号に変換する装置。ブロードバンドルータの「上流」にあることが多い
- **「ホームゲートウェイ」**：通信業界用語。家庭向けの「インターネットの入り口」を総称した言葉

### まとめ

> **ブロードバンドルータ＝「高速回線を受けて、家中の複数機器にインターネットを分配し、IP変換や無線接続も担う、家庭・SOHO向けのネットワーク入り口機器」**

ファイアウォールやBGPが「企業・インターネットの大規模な世界」の話なら、ブロードバンドルータは「**一般家庭のインターネットの顔**」です。
