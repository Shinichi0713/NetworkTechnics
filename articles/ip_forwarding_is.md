SEにネットワークを構築してもらった際にルータから"IPフォワーディング"するといわれた場合に、何やねんそれと。

そんな時に備えてルータの基本機能であるIPフォワーディングについて説明します。

## IPフォワーディングとは
IPフォワーディングとは、コンピューターやサーバーが「自分宛てではないIPパケット」を受け取った際に、別のネットワークや別の機器へ中継（転送）する機能のことです。

### 簡単に言うと？

通常、パソコンやスマートフォンは「自分宛てのデータ」だけを受け取ります。しかし、IPフォワーディングが有効になっている機器は、**他の機器の代わりにデータを届け役**をすることもできます。

### どんな場面で使われるか

1. **ルーターの基本機能**
   インターネットや社内ネットワークのルーターは、IPフォワーディングを使って、届いたパケットを最適な経路へ次々と転送しています。インターネットが成り立っているのは、無数の機器がこのフォワーディングを行っているおかげです。

2. **Linuxサーバーをルーター／ゲートウェイとして使う**
   LinuxサーバーでIPフォワーディングを有効にすると、そのサーバー自体が簡易的なルーターやVPNゲートウェイとして振る舞えます。例えば、プライベートネットワーク内の端末がインターネットに出ていく際の「中継役」として機能させることができます。

3. **コンテナや仮想化環境**
   DockerやKubernetesなどの環境でも、コンテナ間やホストマシンとの通信を中継するために、内部的にIPフォワーディングが使われています。

### Linuxでの設定例

Linuxでは、以下のコマンドで一時的に有効化できます（再起動で消えます）。

```bash
sudo sysctl -w net.ipv4.ip_forward=1
```

永続的に設定する場合は、`/etc/sysctl.conf` などで `net.ipv4.ip_forward=1` と記述します。

### セキュリティ上の注意

IPフォワーディングが不要な一般のPCやサーバーで無闇に有効にしておくと、意図しない経路で通信が流れるリスクがあります。そのため、**ルーターやゲートウェイとしての役割が必要な機器だけで有効にする**のが基本です。
