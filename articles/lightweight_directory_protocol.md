LDAP（Lightweight Directory Access Protocol）は、**ディレクトリサービス**と呼ばれる階層的なデータベースに対して、情報を検索・参照・認証するための通信プロトコルです。

以下に、LDAP の概要と特徴を整理して説明いたします。

## 1. 一言で言うと

LDAP は、**「組織内の電話帳・名簿・権限情報を階層的に管理し、高速に検索・認証するための標準プロトコル」** です。


## 2. なぜ「ディレクトリサービス」なのか

LDAP が扱うデータベースは、通常の関係データベース（RDB）とは異なり、以下の特徴を持ちます。

| 特徴 | 説明 |
|------|------|
| **階層構造（木構造）** | データをツリー状に配置し、組織の部門やドメインに沿って管理できる |
| **読み取り最適化** | 検索・参照が非常に高速で、書き込みは相対的に少ない用途を想定 |
| **分散管理** | 複数サーバー間で情報を複製・分散できる |

> **イメージ**：企業の組織図をデータベース化したもの。本社 → 支社 → 部署 → 社員、という階層で情報が並んでいる。


## 3. データの構造

LDAP では、情報の1件1件を **エントリ** と呼びます。各エントリは以下で構成されます。

- **DN（Distinguished Name）**：エントリの「絶対パス」のような一意識別子
  - 例：`uid=yamada,ou=People,dc=example,dc=com`
- **objectClass**：エントリの「種類」を定義（例：`person`、`organizationalUnit`）
- **属性（Attribute）**：エントリが持つ具体的な情報
  - 例：`cn`（共通名）、`mail`（メールアドレス）、`telephoneNumber` など

```
dc=example,dc=com           ← ドメインルート
  └── ou=People             ← 組織単位（Organizational Unit）
        └── uid=yamada      ← ユーザー「山田」
              ├── cn: Taro Yamada
              ├── mail: yamada@example.com
              └── telephoneNumber: 03-1234-5678
```


## 4. 主な用途

LDAP は以下のような場面で広く使われています。

### ① ユーザー認証（最も一般的）
- 社内システムへのログイン時に、ID・パスワードを LDAP サーバーに問い合わせて照合
- シングルサインオン（SSO）の基盤としても利用

### ② アドレス帳・名簿
- 社員の連絡先、メールアドレス、役職などを一元管理
- メールクライアント（Outlook、Thunderbird など）が LDAP サーバーから連絡先を検索

### ③ 権限・ポリシー管理
- どのユーザーがどのグループに属し、どのリソースにアクセスできるかを管理
- Linux サーバーのユーザー統合（OpenLDAP + NSS/PAM）など


## 5. 代表的な実装

| 製品・サービス | 説明 |
|--------------|------|
| **OpenLDAP** | 最も広く使われるオープンソース実装 |
| **Microsoft Active Directory** | Windows 環境のディレクトリサービス。内部で LDAP を使用 |
| **OpenDJ**、**389 Directory Server** | その他のオープンソース実装 |

## 6. 技術的なポイント

- **ポート番号**：通常は **389**（LDAP）、**636**（LDAPS = LDAP over SSL/TLS）
- **プロトコル**：TCP/IP 上で動作
- **検索が中心**：`search` 操作が最も重要で、フィルタ条件（例：`(&(objectClass=person)(ou=Sales))`）を使って絞り込み検索を行う
- **軽量**：X.500 というより重いディレクトリ標準を簡略化したものが LDAP の由来（Lightweight の意味）


## まとめ

LDAP は、**組織内の人・物・権限情報を階層的に管理し、高速に検索・認証するための標準プロトコル**です。Active Directory や OpenLDAP などの裏側で動いており、企業の IT 基盤における「電話帳兼身分証明システム」として、広く普及しています。
