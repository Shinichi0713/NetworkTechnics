## 概要

**トランクポート（Trunk Port）** とは、**1本の物理イーサネットリンク（ケーブル）上で、複数のVLANのフレームを同時に運ぶためのスイッチポートのモード**です。

通常のポート（アクセスポート）は1つのVLANだけに所属しますが、トランクポートは **「どのVLANのフレームか」をタグ（802.1Q VLANタグ）で識別しながら、複数VLANを混在して転送**します。

### 1. なぜトランクポートが必要か

企業のLANでは、部門ごとにVLANを分けるのが一般的です。

```
【VLANの分離】
VLAN10（営業）  [PC]──[スイッチA]──[PC]
VLAN20（開発）  [PC]──[スイッチA]──[PC]

【スイッチ間を繋ぐ場合】
スイッチAとスイッチBの間に、VLAN10用のケーブルとVLAN20用のケーブルを
それぞれ引くのは非効率
```

トランクポートを使うと、**スイッチ間は1本のケーブルで済みます**。

```
【トランクポートで解決】
[スイッチA] ═══════════════ [スイッチB]
   ↑  1本の物理リンク      ↑
   VLAN10タグ付きフレーム    （タグを見て適切なVLANに振り分ける）
   VLAN20タグ付きフレーム
   VLAN30タグ付きフレーム   ← 複数VLANを同時に運べる
```

> **本質は、「複数のVLANを1本の物理リンクで集約転送し、スイッチ間のケーブルを節約する」ことです。**

### 2. 仕組み：802.1Qタグ

トランクポートが複数VLANを区別する仕組みは、**イーサネットフレームに「VLANタグ」を挿入すること**です（IEEE 802.1Q）。

```
【通常のフレーム（アクセスポート）】
| 目的MAC | 送信元MAC | タイプ | ペイロード | FCS |

【トランクポートで運ばれるフレーム】
| 目的MAC | 送信元MAC | 802.1Qタグ | タイプ | ペイロード | FCS |
                          ↑
                    VLAN ID（12ビット：1～4094）
                    優先度（3ビット：QoS用）
```

- 送信側スイッチ：「このフレームはVLAN20のものだ」とタグを付けて送出
- 受信側スイッチ：タグのVLAN IDを見て、「これはVLAN20のポートに振り分けよう」と判断

### 3. アクセスポートとトランクポートの違い

| 項目 | アクセスポート | トランクポート |
|------|--------------|--------------|
| **所属VLAN** | 1つのVLANに固定 | 複数のVLANを同時に扱う |
| **送受信フレーム** | タグなし（untagged） | タグ付き（tagged）が基本 |
| **接続先** | 通常のPC・プリンター・サーバー | スイッチ、ルーター、ハイパーバイザー |
| **用途** | エンドデバイス接続 | スイッチ間接続、L3スイッチのルーティング用 |

### 4. Native VLAN（ネイティブVLAN）

トランクポートでは、**「タグが付いていないフレーム」も通せます**。これを**Native VLAN**と呼びます。

```
【トランクポート上のフレーム】
タグ付きフレーム（VLAN10） → 「VLAN10です」と明示
タグ付きフレーム（VLAN20） → 「VLAN20です」と明示
タグなしフレーム           → 「Native VLAN（例：VLAN1）のフレーム」と解釈
```

- デフォルトでは多くの機器で **VLAN1** がNative VLAN
- Native VLANの不一致はセキュリティリスクや通信障害の原因になるため、設計時に統一が必要

### 5. 以前の文脈との接続

__広域イーサネット（Q-in-Q）との関係__

以前ご説明した **802.1ad（Q-in-Q）** は、この「トランクポートのタグ」を二重化した技術です。

```
【社内スイッチ間のトランク】
[SW-A] ──802.1Qタグ（VLAN10）──→ [SW-B]

【事業者の広域イーサネット（Q-in-Q）】
[PE] ──802.1ad S-TAG（事業者タグ）──→ [PE]
         外側：事業者のタグ
         内側：顧客のVLANタグ（そのまま保持）
```

つまり、**Q-in-Qは「トランクポートのタグをさらに外側で包む」技術**です。

__VPC（クラウド）との関係__

AWS VPCなどでは、物理スイッチのトランクポートの概念が**仮想化**されています。

- **VPCのサブネット** = VLANに相当する論理分離
- **AWS Direct Connect**の802.1Q VLAN（VIF：Virtual Interface）= トランクポートの概念。1本の物理回線上に「プライベートVIF」「パブリックVIF」をVLANタグで分離

### まとめ

> **トランクポートとは、1本の物理イーサネットリンク上で複数のVLANフレームを802.1Qタグで識別しながら同時に運ぶスイッチポートのモードです。アクセスポートが1つのVLANに固定されるのに対し、トランクポートはスイッチ間やルーター間の接続に使われ、ケーブルの集約とVLAN跨ぎの通信を実現します。Native VLAN（タグなしフレーム）の扱いにも注意が必要で、広域イーサネットのQ-in-Qやクラウドの論理回線分離も、このトランクポートのタグ付け機構を拡張したものです。**
