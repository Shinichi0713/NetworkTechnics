VTEP（VXLAN Tunnel End Point）とは、ネットワーク仮想化技術である **VXLAN（Virtual Extensible LAN）** において、VXLAN トンネルの始点・終点となるネットワーク機器（またはソフトウェア）のことです。

物理ネットワーク（L3 / IPネットワーク）上に仮想的なL2ネットワーク（L2 overlay）を構築する際の「カプセル化（Encapsulation）」と「カプセル化解除（Decapsulation）」を担当します。

### VTEPの主な役割

1. **カプセル化（Encapsulation）**
   * 送信元のVTEPは、仮想マシン（VM）やコンテナが出力した標準的な **イーサネットフレーム（L2）** を受け取ります。
   * これに  **VXLANヘッダー（VNI: VXLAN Network Identifier を含む）** 、 **UDPヘッダー** 、**IPヘッダー** を付加して、既存のIPネットワーク上を通れるパケットに変換して送信します。
2. **カプセル化解除（Decapsulation）**
   * 受信側のVTEPは、IPネットワークを経由して届いたVXLANパケットを受け取ります。
   * ヘッダーを取り除き、元のL2イーサネットフレームに戻して目的のVMや端末に配送します。
3. **MACアドレス表とVTEPの紐付け管理**
   * どの仮想端末のMACアドレスが「どの remote VTEP（対向のVTEPのIPアドレス）」の先にあるかを学習・保持し、適切な宛先VTEPへトンネリングします。

### VTEPの種別

VTEPは実装形態によって大きく2つに分かれます。

* **ハードウェアVTEP（ToRスイッチなど）**
  * 物理ネットワークスイッチ（Arista, Cisco, JuniperなどのTop-of-Rackスイッチ）のASIC上でVTEP機能を動作させます。
  * VXLANに対応していない物理サーバーや既存装置をVXLANネットワークに参加させる際によく使われます。
* **ソフトウェアVTEP（ハイパーバイザー / ホスト）**
  * VMware ESXi（NSX）、Open vSwitch (OVS)、Linuxカーネルモジュールなど、サーバー上のハイパーバイザーやOS内で動作するVTEPです。
  * 仮想化環境内で完結してオーバーレイネットワークを構築できます。

### まとめ

VTEPは「 **物理的なIPネットワーク（アンダーレイ）の上に、拠点やラックを跨いだ巨大な仮想L2空間（オーバーレイ）を作るための入り口兼出口** 」として機能します。
