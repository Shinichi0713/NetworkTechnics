組織ネットワークにおいて、L2（データリンク層）フレームをカプセル化してIPネットワーク（L3）や別のL2網の上でトンネル化・延伸する主な技術には以下のようなものがあります。

---

## 1. 主要なL2トンネリング技術

* **VXLAN (Virtual Extensible LAN)**
* **概要:** L2のイーサネットフレームをUDP/IP（L3）パケットでカプセル化する技術。
* **用途:** データセンターやSDN（Software-Defined Networking）環境で広く活用され、従来のVLAN制限（4,094個）を大幅に超える約1,600万個のネットワークを識別できます。


* **L2TPv3 (Layer 2 Tunneling Protocol version 3)**
* **概要:** イーサネットやPPPなどのL2フレームをIP/UDPで直接カプセル化して伝送する標準プロトコル。
* **用途:** 拠点間をIP網経由で同一L2セグメント（広域イーサネット風）として接続する際によく使われます。


* **GRE (Generic Routing Encapsulation) / L2GRE**
* **概要:** パケットをGREヘッダーでカプセル化する汎用技術。L2フレームをカプセル化するものは特に「Ethernet over GRE (EoGRE)」や「L2GRE」と呼ばれます。
* **用途:** 企業拠点間接続や、Wi-Fiアクセスポイントからのトラフィックをコントローラーへ集約する際などに用いられます。


* **EtherIP (RFC 3378)**
* **概要:** イーサネットフレームをIPパケット（プロトコル番号97）の中に直接組み込んで送信するシンプルなトンネリング技術。
* **用途:** ルーターやファイアウォール間での簡単なL2延伸（ブリッジング）に使用されます。


* **VPLS (Virtual Private LAN Service)**
* **概要:** MPLS（Multi-Protocol Label Switching）網上で、広域にまたがる複数の拠点間をあたかも1つのL2スイッチ（LAN）で接続しているように見せる技術。
* **用途:** 通信事業者が提供する広域イーサネットサービス（IP-VPN / L2-VPN）などで採用されています。


* **NVGRE (Network Virtualization using Generic Routing Encapsulation)**
* **概要:** GREを利用してL2フレームをIPにカプセル化する仮想化オーバーレイ技術（主にMicrosoft主導）。



---

## 2. 暗号化（セキュリティ）を伴うL2トンネリング

上記技術自体には暗号化機能が含まれていないものが多いため、セキュリティが必要な場合は以下の技術が組み合わされます。

* **IPsec (Tunnel Mode) + GRE / L2TP**
* GREやL2TPv3でL2フレームをカプセル化した上で、IPsecを使って通信を暗号化します。


* **MacVTap / Geneve**
* ネットワーク仮想化（NVMe-oFやコンテナ/VM間通信）において標準化が進む汎用カプセル化プロトコルです。
