無線通信の原理は、**「電磁波に情報を乗せて空間を通過させ、受信側で情報を取り出す」** という物理的プロセスです。以下、基礎から段階的に解説します。

---

## 1. 核心アイデア（1文）

> **無線通信は、送信側で電気信号を電磁波に変換・変調して放射し、空間を伝搬した電磁波を受信側で検波・復調して元の情報を復元する過程である。**

---

## 2. 直感的なアナロジー：「投げたボールにメッセージを書く」

- **情報**：ボールに書かれた文字（メッセージ）
- **変調**：ボールの「色」「回転速度」「投げるタイミング」に情報を変換して表現する
- **電磁波**：ボールそのもの（物理的な媒体）
- **伝搬**：ボールが空間を飛んでいく
- **復調**：受け取ったボールから文字を読み取る

重要なのは、ボール（電磁波）がなくては情報を運べないし、ボールの性質（色・回転など）を変えないと情報を乗せられないという点です。

---

## 3. 物理的メカニズム：3つのステップ

### ステップ①：電磁波の生成（送信）

アンテナに**高周波の交流電流**を流すと、電場と磁場が交互に変化しながら空間へ放射されます。これが電磁波です。

電磁波の基本式：

$$
c = f \cdot \lambda
$$

- $c$：光速（約 $3 \times 10^8$ m/s）
- $f$：周波数（Hz）
- $\lambda$：波長（m）

例えば、2.4GHzのWi-Fi電波の波長は：

$$
\lambda = \frac{3 \times 10^8}{2.4 \times 10^9} = 0.125 \text{ m} = 12.5 \text{ cm}
$$

### ステップ②：変調（Modulation）— 情報を乗せる

情報（音声・データ・映像）は低周波の電気信号ですが、そのままではアンテナから効率よく放射できません。そこで**搬送波（Carrier Wave）**という高周波の正弦波に情報を乗せます。

$$
s(t) = A(t) \cdot \cos(2\pi f_c t + \phi(t))
$$

情報は以下の3つのパラメータに乗せられます：

| 変調方式                    | 変えるパラメータ | 具体例           |
| --------------------------- | ---------------- | ---------------- |
| **ASK**（振幅変調）   | 振幅$A(t)$     | AMラジオ         |
| **FSK**（周波数変調） | 周波数$f_c$    | 旧式の無線機     |
| **PSK**（位相変調）   | 位相$\phi(t)$  | GPS、Wi-Fi       |
| **QAM**               | 振幅＋位相の両方 | LTE、5G、Wi-Fi 6 |

### ステップ③：復調（Demodulation）— 情報を取り出す

受信アンテナが電磁波を受け取ると、電磁波のエネルギーが再び電流に変換されます。受信機はこの信号から**搬送波を除去**し、元の情報信号を取り出します。

---

## 4. なぜ「周波数」が重要か？

異なる周波数の電磁波は、性質が大きく異なります。

| 周波数帯                          | 波長       | 性質                             | 用途                       |
| --------------------------------- | ---------- | -------------------------------- | -------------------------- |
| **VLF〜LF**（3kHz〜300kHz） | 長い       | 地表伝搬、遠距離、低データレート | 潜水艦通信                 |
| **HF**（3MHz〜30MHz）       | 中程度     | 電離層反射、大陸間通信           | 短波ラジオ                 |
| **VHF/UHF**（30MHz〜3GHz）  | 数十cm     | 比較的直進性、障害物を回折       | テレビ、FMラジオ、警察無線 |
| **SHF**（3GHz〜30GHz）      | 数cm〜数mm | 高帯域、障害物に弱い、マイクロ波 | Wi-Fi、5G、衛星通信        |
| **EHF**（30GHz〜）          | 数mm以下   | 超広帯域、大気吸収あり           | 5Gミリ波、衛星間通信       |

**基本原則**：周波数が高いほど運べる情報量は増えますが、障害物を貫通する力（回折性）は弱くなります。

---

## 5. 通信の限界：シャノンの定理

無線通信の理論的限界を示す最も重要な式です。

$$
C = B \cdot \log_2\left(1 + \frac{S}{N}\right)
$$

- $C$：チャネル容量（bps、一秒間に運べる最大ビット数）
- $B$：帯域幅（Hz、使用する周波数の幅）
- $S/N$：信号対雑音比（Signal-to-Noise Ratio）

### この式が教えること

1. **帯域幅 $B$ を広げれば、運べる情報量 $C$ は増える**
2. **SNRを上げれば（電波を強くすれば、雑音を減らせば）、情報量は増える**
3. **ただし、理論的な上限が存在する**

SilvusのMN-MIMOが高スループットを出せるのは、MIMOによって**同一帯域 $B$ で空間的に複数の独立チャネルを作り**、実効的に $B$ を増やしているからです。

---

## 6. 無線通信の基本構成要素

```
【送信側】
情報源 → 符号化 → 変調 → 送信アンテナ → 電磁波放射

【空間】
電磁波の伝搬（直進・反射・回折・散乱）

【受信側】
受信アンテナ → 復調 → 復号 → 情報復元
```

### 伝搬における現象

| 現象                   | 説明                   | 影響                       |
| ---------------------- | ---------------------- | -------------------------- |
| **直進**         | 視界内を直線的に進む   | 最も安定した伝搬           |
| **反射**         | 建物・地面などで反射   | マルチパス（遅延波）を生む |
| **回折**         | 障害物の端で曲がる     | 障害物の陰に届く           |
| **散乱**         | 粗い表面で乱反射       | 信号の減衰とぼやけ         |
| **フェージング** | 波の干渉による強度変動 | 信号品質の変動             |

---

## 7. まとめ

無線通信の原理は以下の3点に集約されます。

| 要素                   | 内容                                                    |
| ---------------------- | ------------------------------------------------------- |
| **物理的基盤**   | 電磁波の生成・放射・伝搬・受信                          |
| **情報の乗せ方** | 変調（振幅・周波数・位相を変化させて情報を符号化）      |
| **限界**         | シャノンの定理（帯域幅とSNRで決まる理論的最大通信速度） |

SilvusのMN-MIMOがこれらをどう発展させているかというと、**「同一帯域・同一時間で、空間的に複数の独立した通信路を作る」**ことで、シャノンの限界を単一リンクではなく**ネットワーク全体で再定義**しているのです。
