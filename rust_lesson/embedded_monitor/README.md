# 組込みリアルタイムモニタリング・シミュレータ

エンベデッドシステムスペシャリスト試験の論文対策にもなる、Rust製の組込みシステムシミュレータです。

## 概要

産業用モニタリング端末を想定し、以下の組込み開発でよくある要素を一つのアプリケーションにまとめました。

- 複数センサー（温度・振動・電圧）のリアルタイムデータ収集
- 移動平均フィルタによるノイズ除去
- 閾値ベースの異常検知
- リングバッファによる固定長ログ管理
- コマンド応答型の簡易通信プロトコル

## 実行方法

```bash
cargo run
```

リリースビルド（サイズ最適化済み）:
```bash
cargo run --release
```

## 画面の見方

```
[   10s]  温度:65.32  動:1.45  電圧:4.52
```

先頭に `!` が付くと異常値です。

## 論文の題材として使えるポイント

- **技術的特徴**: センサー融合、リアルタイムフィルタリング、異常検知アルゴリズム
- **制約**: リングバッファによる固定メモリ使用、サンプリング周期の保証
- **保守・運用**: 異常ログの蓄積と通信プロトコルによる外部監視
- **ハード・ソフト分担**: ADC取得（HW）→ フィルタ・判定（SW）→ 信（SW）
